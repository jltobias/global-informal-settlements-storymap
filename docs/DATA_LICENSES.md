# Data licensing

The repository code is MIT licensed. Upstream data are **not relicensed** by this repository.

The checked-in synthetic demonstration data are CC0-style synthetic test content. For real data, retain the license given by the original provider and include attribution in feature properties and story text. The World Bank EO4SD examples in the source registry are cataloged as Creative Commons Attribution 4.0. WDI metadata also identifies a CC BY 4.0 license for the referenced indicator.
