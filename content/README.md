# Global Informal Settlements Storymap — JupyterLite content

## Start with the live story

Open `showcase/Ekurhuleni_Informal_Settlements_Story_Map.jGIS`. It uses live City of Ekurhuleni municipal informal-settlement polygons and contains six guided story chapters.

Then explore:

- `global/global_index.jGIS` — global entry map
- `notebooks/00_Welcome.ipynb` — repository orientation
- `notebooks/04_Country_Storymap_Builder.ipynb` — generate country stories
- `countries/` — generated country projects

The `countries/XDM` project is synthetic and retained only for pipeline testing; the Ekurhuleni showcase is the real-data presentation example.
