# Live story-map showcase

Open **`Ekurhuleni_Informal_Settlements_Story_Map.jGIS`** with JupyterGIS.

This example deliberately uses a **live public municipal polygon layer**, not the repository's synthetic smoke-test data. The geometry is fetched from the City of Ekurhuleni ArcGIS REST service when the document opens.

## What to try

1. Switch the Story panel into Preview/Presentation mode.
2. Step through the six guided chapters.
3. Use the Identify tool and click an orange polygon.
4. Inspect settlement name, households, hectares, ward, classification and service fields when available.

The story demonstrates the intended pattern for country stories while keeping source provenance visible.
